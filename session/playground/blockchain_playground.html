⛓ Blockchain Playground

Works fully offline · SHA-256

1 · Hash

Type anything. Change one character and the hash changes completely (avalanche effect). Same input → always the same hash.

2 · Chain of blocks

Each block stores the previous block's hash. A block is valid (green) only if its hash starts with the required zeros. Edit the data in block 2 and watch every later block turn red. Then try to "fix" history by re-mining — you must re-mine every block after it.
